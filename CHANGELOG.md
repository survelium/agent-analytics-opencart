# Changelog

All notable changes to `agent-analytics-opencart` will be documented in this file.

## 0.1.0 - 2026-10-15

- First version: a drop-in folder loaded through `auto_prepend_file`, settings in `config.php`, `/admin` left out,
  buffer in a web-blocked `storage` folder, `status.php` to check and send from SSH. Parses on PHP 5.6+ and only
  runs on PHP 8.1+.
